# 성삼국지 촉한영걸전 - Native Android

이 디렉터리는 Winlator/Wine 의존성을 제거하고 게임을 Android 네이티브 앱으로 재구현하기 위한 작업 공간입니다.

## 목표

- APK 하나 설치 후 바로 실행
- Winlator, Wine, Windows 컨테이너 사용 안 함
- 기존 game1/game2의 데이터는 최대한 재사용
- 원작 전투/이벤트/맵 동작을 보존
- 터치 입력, 화면 비율, 저장 경로는 Android에 맞게 재설계

## 현재 구현 상태 (v0.6)

- 실제 첫 전투 맵 `map/m000.jpg` 네이티브 렌더링
- `RS/S_00.eex`의 플레이어/우군/적군 초기 배치 반영
- `Data.e5`의 CP949 한글 인물명 사용
- `Ekd5.exe`의 S형상 지정과 `Unit_mov.e5` / `Unit_spc.e5` / `Spalet.e5` 원본 스프라이트 연결
- `S_00.eex` 오프닝 이벤트에서 대사, 등장/숨김, 이동, 회전, 동작, 퇴각, 지연, BGM/SFX 지시 추출
- Android에서 오프닝 이벤트 순차 재생 및 대사 터치 진행
- 오프닝 종료 후 플레이어 유닛 선택/빈 타일 이동
- 드래그 이동 및 핀치 줌

현재 BGM/SFX는 이벤트 번호만 추적하며 실제 음원 재생은 아직 구현하지 않았습니다. 이동 가능 범위, 지형 비용, 공격/책략, 피해 계산, AI와 승패 조건도 다음 단계입니다.

## 구현 방향

1. **데이터 카탈로그 작성**
   - 파일명/크기/해시/확장자/중복 여부 정리
2. **맵/전투 데이터 분석**
   - Mmap.e5, Pmap.e5, Pmapobj.e5, Hexzmap.e5, map/, RS/*.eex 분석
3. **그래픽/폰트/사운드 분석**
   - Unit_mov/Unit_spc/Spalet, 이미지 리소스, 폰트, BGM/효과음 구조 분석
4. **Android 네이티브 렌더러**
   - Android Canvas 기반 프로토타입에서 시작해 필요한 경우 OpenGL ES로 확장
5. **게임 로직 재구현**
   - 이동 범위/지형, 전투 계산, AI, 이벤트, 메뉴, 세이브
6. **모바일 UI**
   - 터치 선택, 스크롤, 확대/축소, 뒤로가기, 전투 명령 UI
7. **원터치 APK**
   - 필요한 원본 데이터를 빌드 시 패키징하여 설치 후 바로 실행

## 다음 완료 기준

첫 전투에서 **원본 오프닝 이벤트가 끝난 뒤 실제 이동 가능 범위와 지형 비용을 적용하고, 공격 대상 선택과 1회 전투 계산까지 네이티브로 수행**하는 것.
