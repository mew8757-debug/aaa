# 성삼국지 촉한영걸전 - Native Android

이 디렉터리는 Winlator/Wine 의존성을 제거하고 게임을 Android 네이티브 앱으로 재구현하기 위한 작업 공간입니다.

## 목표

- APK 하나 설치 후 바로 실행
- Winlator, Wine, Windows 컨테이너 사용 안 함
- 기존 game1/game2의 데이터는 최대한 재사용
- 원작 전투/이벤트/맵 동작을 보존
- 터치 입력, 화면 비율, 저장 경로는 Android에 맞게 재설계

## 현재 구현 상태 (v1.7)

- 실제 첫 전투 맵 `map/m000.jpg` 네이티브 렌더링
- `RS/S_00.eex`의 플레이어/우군/적군 초기 배치 반영
- `Data.e5`의 CP949 한글 인물명 사용

- `S_00.eex` 오프닝 이벤트의 대사, 등장/숨김, 이동, 회전, 동작, 퇴각, 지연, BGM/SFX 지시 순차 재생

## v1.7 전투·이벤트·AI 범위

현재 피해 계산은 역분석에서 확인된 핵심 공방차를 사용해 `max(ATK - DEF, 0)`으로 결정적으로 처리합니다. 승패와 목표 전환은 `S_00.eex`에서 읽은 실제 인물 코드·좌표·턴 제한·목표 텍스트를 사용합니다.

아직 다음 요소는 적용하지 않습니다.

- 장비 공격/방어 보정
- 지형의 전투 능력 보정
- 병종 상성
- 명중/회피
- 치명타/연타
- 관통/특기
- Scene 2의 나머지 위치/인접/인원수 트리거 이벤트 자동 해석

전투 패널을 만드는 데 사용한 인물 오능, 직업 성장, 레벨, 초기 HP 원천값을 `battle0.json`에 함께 남겨 이후 실기/런타임 역분석 결과로 계산식을 교체할 수 있게 했습니다.

## 구현 방향

1. **데이터 카탈로그 작성**
   - 파일명/크기/해시/확장자/중복 여부 정리
2. **맵/전투 데이터 분석**
   - Mmap.e5, Pmap.e5, Pmapobj.e5, Hexzmap.e5, map/, RS/*.eex 분석
3. **그래픽/폰트/사운드 분석**
   - Unit_mov/Unit_atk/Unit_spc/Spalet, 이미지 리소스, 폰트, BGM/효과음 구조 분석
4. **Android 네이티브 렌더러**
   - Android Canvas 기반 프로토타입에서 시작해 필요한 경우 OpenGL ES로 확장
5. **게임 로직 재구현**
   - 이동 범위/지형, 전투 계산, AI, 이벤트, 메뉴, 세이브
6. **모바일 UI**
   - 터치 선택, 스크롤, 확대/축소, 뒤로가기, 전투 명령 UI
7. **원터치 APK**
   - 필요한 원본 데이터를 빌드 시 패키징하여 설치 후 바로 실행
