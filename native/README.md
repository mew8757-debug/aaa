# Native Android Engine 연구 영역

이 디렉터리는 2단계 목표인 **Windows EXE 없이 조조전 MOD 데이터를 직접 읽는 Android 엔진**을 위한 작업 공간입니다.

## 목표 순서
1. 파일 인벤토리 수집
2. E5/EEX 및 기타 데이터 파일 헤더 식별
3. 맵/스프라이트/음원 추출기
4. 이벤트 스크립트 디코더
5. 맵 뷰어
6. 유닛 이동/전투 로직
7. 이벤트 엔진
8. 세이브 호환 또는 변환기

## 원칙
- 게임 저작권 리소스는 이 저장소에 업로드하지 않습니다.
- 분석기는 사용자가 로컬에서 보유한 게임 데이터를 입력으로 받도록 만듭니다.
- 원본 Windows 엔진의 동작을 기준점으로 삼아 기능별로 재현합니다.

현재는 1단계 런처가 먼저 안정화된 뒤, 실제 성삼국지 파일 인벤토리를 확보해 포맷별 분석기를 추가합니다.
