# 성삼국지 촉한영걸전 - Native Android

이 디렉터리는 Winlator/Wine 의존성을 제거하고 게임을 Android 네이티브 앱으로 재구현하기 위한 작업 공간입니다.

## 목표

- APK 하나 설치 후 바로 실행
- Winlator, Wine, Windows 컨테이너 사용 안 함
- 기존 game1/game2의 데이터는 최대한 재사용
- 원작 전투/이벤트/맵 동작을 보존
- 터치 입력, 화면 비율, 저장 경로는 Android에 맞게 재설계

## 현재 구현 상태 (v1.0)

- 실제 첫 전투 맵 `map/m000.jpg` 네이티브 렌더링
- `RS/S_00.eex`의 플레이어/우군/적군 초기 배치 반영
- `Data.e5`의 CP949 한글 인물명 사용
- `Ekd5.exe`의 S형상 지정과 `Unit_mov.e5` / `Unit_atk.e5` / `Unit_spc.e5` / `Spalet.e5` 원본 스프라이트 연결
- `S_00.eex` 오프닝 이벤트의 대사, 등장/숨김, 이동, 회전, 동작, 퇴각, 지연, BGM/SFX 지시 순차 재생
- `Hexzmap.e5` M000 블록의 23x16 실제 지형 ID 사용
- `Data.e5` 상세병종의 실제 이동력과 병종계열별 30종 지형 이동비용 적용
- 가중치 기반 이동 가능 범위와 최소 이동비용 경로 적용
- `0x46/0x47` 실제 배치 레벨을 읽어 전투 패널 생성에 반영
- 인물 오능, 초기 HP, 상세병종 성장치를 전투 패널 원천값으로 보존
- HP / ATK / DEF 전투 상태와 원본 공격 모션 표시
- 공격 범위 ID 0(십자 인접), 1(주변 1칸) 대상 강조 및 터치 공격
- 첫 물리 피해 계산과 격파 처리
- 아군 턴당 1회 이동 + 공격 행동 상태
- 공격 후 생존 피격자의 사거리 내 반격
- 화면 우하단 `턴 종료` 버튼과 아군/적군 턴 전환
- 적군이 원본 지형 이동비용으로 가장 가까운 비적군 유닛을 추적해 이동/공격
- 다음 아군 턴 시작 시 이동/행동 상태 초기화
- `S_00.eex` 원본 1단계 목표: 우리군/우군이 `(6,13)` 마을에 도착
- 마을 도착 시 원본 Section 2-1의 백성5·추정·유비 이벤트와 목표 전환 재생
- 원본 `0x5D` 값에 따라 2단계 회합 상한 15턴 적용
- 원본 2단계 목표: 적군 전멸
- 유비(0)·추정(181) 사망, 1단계 적군 `(13,11)` 마을 진입, 턴 초과 패배 처리
- 전투 종료 시 승리/패배 상태로 입력과 AI 정지
- 드래그 이동 및 핀치 줌

## v1.0 전투 계산 및 승패 범위

현재 피해 계산은 역분석에서 확인된 핵심 공방차를 사용해 `max(ATK - DEF, 0)`으로 결정적으로 처리합니다. 승패와 목표 전환은 `S_00.eex`에서 읽은 실제 인물 코드·좌표·턴 제한·목표 텍스트를 사용합니다.

아직 다음 요소는 적용하지 않습니다.

- 장비 공격/방어 보정
- 지형의 전투 능력 보정
- 병종 상성
- 명중/회피
- 치명타/연타
- 관통/특기
- Scene 2의 나머지 위치/인접/인원수 트리거 이벤트 자동 해석

전투 패널을 만드는 데 사용한 인물 오능, 직업 성장, 레벨, 초기 HP 원천값을 `battle0.json`에 함께 남겨 이후 실기/런타임 역분석 결과로 계산식을 교체할 수 있게 했습니다.

## 구현 방향

1. **데이터 카탈로그 작성**
   - 파일명/크기/해시/확장자/중복 여부 정리
2. **맵/전투 데이터 분석**
   - Mmap.e5, Pmap.e5, Pmapobj.e5, Hexzmap.e5, map/, RS/*.eex 분석
3. **그래픽/폰트/사운드 분석**
   - Unit_mov/Unit_atk/Unit_spc/Spalet, 이미지 리소스, 폰트, BGM/효과음 구조 분석
4. **Android 네이티브 렌더러**
   - Android Canvas 기반 프로토타입에서 시작해 필요한 경우 OpenGL ES로 확장
5. **게임 로직 재구현**
   - 이동 범위/지형, 전투 계산, AI, 이벤트, 메뉴, 세이브
6. **모바일 UI**
   - 터치 선택, 스크롤, 확대/축소, 뒤로가기, 전투 명령 UI
7. **원터치 APK**
   - 필요한 원본 데이터를 빌드 시 패키징하여 설치 후 바로 실행
