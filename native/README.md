# 성삼국지 촉한영걸전 - Native Android

이 디렉터리는 Winlator/Wine 의존성을 제거하고 게임을 Android 네이티브 앱으로 재구현하기 위한 작업 공간입니다.

## 목표

- APK 하나 설치 후 바로 실행
- Winlator, Wine, Windows 컨테이너 사용 안 함
- 기존 game1/game2의 데이터는 최대한 재사용
- 원작 전투/이벤트/맵 동작을 보존
- 터치 입력, 화면 비율, 저장 경로는 Android에 맞게 재설계

## 구현 방향

1. **데이터 카탈로그 작성**
   - 파일명/크기/해시/확장자/중복 여부 정리
2. **맵 포맷 분석**
   - Mmap.e5, Pmap.e5, Pmapobj.e5, Hexzmap.e5, map/ 분석
3. **그래픽/폰트/사운드 분석**
   - 이미지 DLL/리소스, 폰트 파일, BGM/효과음 구조 분석
4. **Android 네이티브 렌더러**
   - SurfaceView/OpenGL ES 기반 2D 렌더러
5. **게임 로직 재구현**
   - 이동, 전투 계산, AI, 이벤트, 메뉴, 세이브
6. **모바일 UI**
   - 터치 선택, 스크롤, 확대/축소, 뒤로가기, 가상 키
7. **원터치 APK**
   - 데이터 내장 또는 최초 실행 시 내부 설치

## 첫 번째 완료 기준

Android 앱에서 Windows/Wine 없이 **첫 번째 실제 게임 맵을 렌더링**하는 것.
