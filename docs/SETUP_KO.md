# 성삼국지 촉한영걸전 Android 실행 설정

## 1. 준비
- Android 스마트폰
- Winlator 또는 호환 포크
- 사용자가 보유한 성삼국지 촉한영걸전 게임 폴더

## 2. 게임 데이터 배치
game1/game2로 나뉘어 있던 파일은 Android에서 **원래 하나의 게임 폴더 구조로 합쳐서** 사용합니다.
예시:

```
/storage/emulated/0/Games/SeongSamgukji/
  게임실행.exe
  ...
  Map/
  Sound/
  ...
```

## 3. Winlator 설정
1. Winlator에서 새 컨테이너를 생성합니다.
2. 게임 폴더가 보이는 드라이브를 연결합니다.
3. 게임의 메인 EXE를 실행합니다.
4. 정상 실행되는 EXE에 대해 Winlator 바로가기를 만듭니다.
5. 가능한 Winlator 버전에서는 바로가기를 Frontend/공유 저장소로 내보냅니다.

## 4. 런처 설정
1. 이 프로젝트에서 빌드한 APK를 설치합니다.
2. 설치된 Winlator 패키지를 선택합니다.
3. 내보낸 `.desktop` 파일의 실제 경로를 입력합니다.
4. **설정 저장**을 누릅니다.
5. **게임 실행**으로 테스트합니다.

직접 실행이 지원되지 않는 Winlator 포크에서는 자동으로 Winlator 메인 화면으로 이동합니다.

## 주의
- 게임 원본 파일은 APK에 포함하지 않습니다.
- 세이브 데이터도 가능하면 게임 폴더 쪽에 유지합니다.
- 각 Winlator 포크는 내부 Activity 이름이나 바로가기 저장 방식이 다를 수 있어 실기기 테스트 후 호환 목록을 갱신해야 합니다.
